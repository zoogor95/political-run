# Board geometry

Generated by `packages/mapbuild`; don't edit these files by hand. To rebuild:

```bash
pnpm maps
```

That downloads the pinned boundary files into `.cache/map-sources` (about 41 MB, checked by sha256) and rewrites every `<id>.json` here. The build is deterministic: the same sources always give byte-identical files.

| Board | Regions | Seats | Notes |
|---|---|---|---|
| `uk` | 12 nations and English regions | 650 | Real 2024 seat counts |
| `pk` | 104 district groups | 266 | Districts merged so no province has more regions than seats. Karachi 22, Lahore 14 and Islamabad 3 are real; the rest are sample values. Jammu and Kashmir is grey and not in play. |
| `in` | 36 states and union territories | 543 | Placeholder outline for development only; the released map must use official Survey of India boundaries |
| `my` | 16 states and territories | 222 | East Malaysia moved closer to the peninsula to fit the screen |
| `us` | 50 states and DC | 538 | 2024 electoral votes; Alaska and Hawaii as insets; Maine and Nebraska played whole |

Each file holds board-space SVG paths for every region, a label point for its seat badge, a `small` flag for regions the renderer draws enlarged, the country outline, and its credits.
